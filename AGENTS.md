# Project instructions

- Use only providers explicitly listed in the local DSH plugin's `allowedProviders`. Never add an official DeepSeek API provider or silently fall back to another provider.
- Keep this MCP small. Add requested features individually after the v1.0 baseline.
- Avoid excessive review, tests or project structure. Use only the checks necessary for the requested change.
- Keep local credentials, config backups and node_modules out of Git.
